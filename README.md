# EO Python Courses

**Private course materials for registered participants**

Welcome to EO Python Courses, the teaching repository for Earth observation, environmental monitoring, and natural-hazard analysis using Python and Google Earth Engine (GEE).

**Instructor:** Amirhossein Ahrari  
Postdoctoral Researcher, University of Oulu · Google Developer Expert (Google Earth Engine)

## Current course

### Natural Hazard Detection and Monitoring using GEE and Python

The course includes practical workflows covering:
- Flood detection using SAR and flood impacts using NDVI
- Heavy precipitation, heatwaves, and coldwaves
- Drought monitoring and drought risk mapping
- Dust storms, dust events, and air pollution monitoring
- Wildfire change detection using optical and radar imagery
- Deforestation and its drivers
- Lake desiccation monitoring

**Format:** 12 sessions, approximately 1 hour each. Exercises use Python, GEE, and Google Colab. Session recordings are shared separately with registered participants.

## Getting started

1. Accept the private repository invitation using your GitHub account.
2. Open the relevant course and session folder.
3. Download the notebook or open it in Google Colab, if applicable.
4. Follow the notebook's instructions to access any required Earth observation datasets.
